Простой процедурный плагин для шаринга корзины WooCommerce с фиксацией "Имени врача" в заказ.

== Возможности ==
* Генерация уникальной ссылки из корзины с ФИО врача
* Публичная страница с перечнем товаров
* Импорт в корзину пациента по клику
* Имя врача записывается в мета заказа и в email админа
* Админ-страница с очисткой старых ссылок
* Шорткод [sharecart_button] и автопанель в корзине

== Установка ==
1. Скопируйте папку sharecart-minimal в /wp-content/plugins/
2. Активируйте плагин
3. Сохраните "Постоянные ссылки" (на всякий случай)
4. На странице "Корзина" появится панель "Поделиться корзиной", либо используйте шорткод

ЧЕКЛИСТ ПОСЛЕ УСТАНОВКИ (что проверить и что может сломаться)
Таблица БД
— Есть ли wp_sharecart_shared? Если нет → повторно активируйте плагин, проверьте dbDelta().

Rewrite
— Перейдите на /share-cart/test/ (должна выдать “Ссылка не найдена”, а не 404).
— Если 404 → «Настройки → Постоянные ссылки → Сохранить».

Панель в корзине / шорткод
— В корзине появился тоггл.
— Шорткод [sharecart_button] работает в Elementor/странице.

Генерация ссылки
— Введите ФИО → “Создать ссылку” → получаете URL вида /share-cart/{uuid}/, копирование работает.
— Если ошибка nonce/403 → смотрите, грузится ли assets/sharecart.js и есть ли ShareCartVars в консоли.

Страница ссылки
— Открывается, видны товары, показано ФИО врача.
— Если “Срок истёк” слишком рано → проверьте часы сервера/таймзону.

Импорт в корзину
— Нажмите “Добавить” → редирект на /cart/.
— Если “cart not initialized” в логах → убедитесь, что в AJAX есть wc_load_cart() (оно есть в коде).

Имя врача в заказе
— Оформите заказ → в админке в метабоксе справа должно быть ФИО.
— В “Произвольных полях” должна быть _ref_doctor_name.

Email админа
— Проверьте, что приходит строка “Имя врача: …”.
— Если нет — шаблон письма переопределён темой; фильтр woocommerce_email_order_meta_fields должен сработать в любом случае.

Очистка старых ссылок
— Админка → ShareCart → Очистить старше N дней → “Удалено записей: X”.
— Если 0, но должны удаляться → проверьте поле expires_at/времена сервера.

Логи/Дебаг
— Включите WP_DEBUG_LOG и гляньте wp-content/debug.log. Не должно быть Notice/Warning.
— В ключевых точках есть error_log() и wc_get_logger()->error/debug() (источник sharecart).

Гости
— Создание и импорт работают без авторизации. Если нет — проверьте наличие хуков nopriv у AJAX.

Clipboard
— В Safari/HTTP может не работать авто-копирование → fallback через кнопку “Скопировать”.
